# 本机 AMLT 环境记录

复制本文件为同目录的 `my-env.md` 后填写。`my-env.md` 已被 Git 忽略，
只保留在本机；不要在模板中写入真实凭据或访问令牌。

- 项目目录：`<project-directory>`
- 项目名称：`<project-name>`
- 工作区：`<workspace-name>`
- 计算目标：`<target-name>`
- 存储账户 / 容器：`<storage-account>` / `<container-name>`
- 任务内挂载路径：`<mount-path>`
- 用户分配的托管身份（UAI，用于访问 Azure 资源）：`<identity-name>`

具体值应从当前项目配置或 AMLT 查询结果中核实。
凭据请通过本机凭据管理或环境变量提供，不要提交到仓库。
